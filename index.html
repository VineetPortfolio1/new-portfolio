Story

How the path adds up.

I started in technical support and QA at Sony in 2019, the year I finished my B.Tech at Krishna Engineering College. The work was troubleshooting software and network problems for clients.

In November 2020 I moved into front-end work as a developer trainee at Magic Software. I built responsive pages from PSD, PDF and Figma files, wrote W3C-compliant markup, deployed over FTP and sent a project status report every day.

Freelance work for clients followed (September 2022 to February 2023). Since March 2023 I've been at Webware.io, working in React.js and Tailwind CSS, championing accessibility, and building a documented component library.

Process

The three words in the headline, and what each one covers in my work.

Spec

  • Start from the Figma file, or the PSD or PDF on earlier projects.
  • Translate it into responsive layouts that match the spec to the pixel.
  • Pull repeated pieces into reusable components.

Build

  • Semantic HTML, styled with Tailwind CSS or Sass.
  • React.js components in JavaScript (ES6+).
  • RESTful API integration with backend teams, including async data binding and state management.
  • Git and JIRA, in Agile sprints.

Verify

  • Cross-browser and responsive checks.
  • WCAG 2.1 AA audits and refactors.
  • Core Web Vitals (LCP/FID), bundle size and asset delivery.
  • W3C-compliant markup, and email builds with Litmus in the toolkit.

Then I document it: component docs for the team, and plain-language notes for stakeholders who don't code.
